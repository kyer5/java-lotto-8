# java-lotto-precourse

> 우아한테크코스 8기 프리코스 3주차, 로또

## 💁🏻‍♀️ 프로그램 개요

사용자가 입력한 금액만큼 로또를 발행하고, 당첨 번호 + 보너스 번호와 비교하여 당첨 결과 및 수익률을 확인할 수 있는 프로그램입니다.

## 🚀 주요 기능

1. **로또 구입 및 발행**
    - 사용자가 입력한 금액만큼 로또를 발행합니다.
    - 각 로또는 1~45 사이의 중복되지 않은 숫자로 구성됩니다.
2. **당첨 결과 확인 및 수익률 계산**
    - 구매한 로또와 당첨 번호 + 보너스 번호를 비교해 당첨 결과를 계산합니다.
    - 등수별 당첨 내역과 총 수익률을 출력합니다.

## 📝 구현할 기능 목록

> 각 유효성 검증에 대한 내용은 아래 ‘**예외 발생 상황 및 메시지**’에서 확인합니다.

### 1. 로또 구입

(로또 1장의 가격은 1,000원이다)

- 사용자로부터 구입 금액을 입력 받는다.
- 구입 금액의 유효성 검증을 진행한다.

### 2. 로또 발행

- 구입 금액에 따라 로또를 발행한다.
    - 로또 1장은 1~45 사이의 숫자 6개로 구성한다.
- 수량과 각 로또의 번호를 오름차순으로 정렬하여 출력한다.

### 3. 당첨 번호

- 사용자로부터 당첨 번호를 입력 받는다.
    - 당첨 번호는 서로 중복되지 않는 6개의 숫자로 구성되어야 한다.    
    - 각 번호는 쉼표(`,`)를 기준으로 구분한다.
- 당첨 번호에 대한 유효성 검증을 진행한다.

### 4. 보너스 번호

- 사용자로부터 보너스 번호 1개를 입력 받는다.
    - 보너스 번호는 당첨 번호와 중복되지 않는 숫자여야 한다.
- 보너스 번호에 대한 유효성 검증을 진행한다.

### 5. 당첨 결과

- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역을 출력한다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.

    ```
    1등: 6개 번호 일치 / 2,000,000,000원
    2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    3등: 5개 번호 일치 / 1,500,000원
    4등: 4개 번호 일치 / 50,000원
    5등: 3개 번호 일치 / 5,000원
    ```

### 6. 수익률 계산

- 구입 금액 대비 당첨금의 비율로 수익률을 계산한다. 계산식은 아래와 같다.

    ```
    수익률 = (당첨금 총합 / 구입 금액) x 100
    ex. 로또 8장(8,000원) 구입, 5등(5,000원) 당첨
    → (5,000 / 8,000) x 100 = 62.5%
    ```

- 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.

## ⌨️ 입출력 예시

### **입력**

- 로또 구입 금액 입력 (1,000원 단위)

    ```
    14000
    ```

- 당첨 번호 입력 (쉼표(`,`)로 구분)

    ```
    1,2,3,4,5,6
    ```

- 보너스 번호 입력

    ```
    7
    ```

### **출력**

- 발행한 로또 수량 및 번호 출력 (오름차순 정렬)

    ```
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43] 
    [3, 5, 11, 16, 32, 38] 
    [7, 11, 16, 35, 36, 44] 
    [1, 8, 11, 31, 41, 42] 
    [13, 14, 16, 38, 42, 45] 
    [7, 11, 30, 40, 42, 43] 
    [2, 13, 22, 32, 38, 45] 
    [1, 3, 5, 14, 22, 45]
    ```

- 당첨 내역 출력

    ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```

- 수익률 출력 (소수점 둘째 자리에서 반올림)

    ```
    총 수익률은 62.5%입니다.
    ```

## 🚨 예외 발생 상황 및 메시지

> 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
`Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

1. **로또 구입 금액 입력**
    - 숫자(정수) 이외의 다른 문자가 포함되어있는 경우 (공백만 입력 포함)

      → `[ERROR] 로또 구입 금액은 숫자(정수)로만 입력할 수 있습니다.`

    - 구입 가능 범위(1,000원~100,000원)를 벗어난 경우

      → `[ERROR] 로또 구입은 최소 1,000원부터 최대 100,000원까지 가능합니다.`

    - 1,000원 단위로 구입하지 않은 경우

      → `[ERROR] 로또는 1,000원 단위로 구입할 수 있습니다.`

2. **당첨 번호 & 보너스 번호 입력 공통**
    - 로또 숫자(정수) 범위를 벗어난 경우

      → `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`

3. **당첨 번호 입력**
    - 숫자(정수)와 쉼표(`,`) 이외의 다른 문자를 입력한 경우

      → `[ERROR] 허용되지 않은 문자가 포함되어 있습니다. (옳은 입력 예시: 1,2,3,4,5,6)`

    - 로또 번호가 6개가 아닌 경우

      → `[ERROR] 로또 번호는 6개여야 합니다.`

4. **보너스 번호 입력**
    - 숫자(정수)가 아닌 다른 문자를 입력한 경우

      → `[ERROR] 보너스 번호는 숫자(정수) 하나만 입력할 수 있습니다.`

    - 당첨 번호와 중복된 번호를 입력한 경우

      → `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`

## 🤔 기능 요구 사항에 기재되지 않은, 스스로 판단한 기준

1. **로또 구입 가능 범위**
    - 로또는 최소 1,000원부터 최대 100,000원 범위 내에서 구입할 수 있다.

      > 실제 로또 구입은 1회 최대 10만원까지만 가능하다.
